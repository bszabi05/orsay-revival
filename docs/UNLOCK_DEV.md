# 🔓 Developer Mode & Login (Orsay OS)

On 2015 Samsung Smart TVs (J-series, Orsay OS), installing custom applications requires creating and logging into a hidden developer account.

## 1. Creating the "develop" Account
1. Press the **Smart Hub** button on your remote.
2. Navigate to **Samsung Account** or **Login** (usually located at the bottom of the screen or within the settings menu).
3. Select **Create Account**.
4. For the Samsung Account ID (Username), type exactly: `develop`
5. Leave the password field empty. *(Note: If the system forces you to enter a password, use a simple 6-character dummy password like `123456`, though the passwordless method works on most firmware versions).*
6. Accept the terms of service and save the account.

## 2. Logging In
1. Return to the Smart Hub login screen.
2. Log in using the newly created `develop` account.
3. Upon successful login, the word "develop" should appear in the bottom-left corner of the screen or on your profile icon. The TV is now in Developer Mode.
